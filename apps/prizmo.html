Prizmo ​

Prizmo is a professional scanning app with OCR for iPhone, iPad, and Mac. Protocol Launcher allows you to generate deep links to process documents and read text aloud in Prizmo.

Usage ​

There are two ways to use this library:

  • On-Demand import from subpaths enables tree-shaking and keeps bundles small.
  • Full Import from the root package is convenient but includes all app modules.

Pick On-Demand for production builds; Full Import is fine for quick scripts or demos.

Select Installation Method

On-Demand
Recommended. Optimized for production.
Full Import
Convenient. Good for quick scripts.

Process Document ​

Process a document in Prizmo with OCR, PDF generation, and image cleanup.

On-Demand
ts
import { processDocument } from 'protocol-launcher/prizmo'

const url = processDocument({
  ocr: 'en',
  destination: 'clipboard',
})
Process Document in Prizmo

Process Document with Callback ​

Process a document with callback URLs for success, cancel, and error events.

On-Demand
ts
import { processDocument } from 'protocol-launcher/prizmo'

const url = processDocument({
  ocr: 'en',
  destination: 'url',
  xSuccess: 'myapp://callback',
})
Process Document with Callback

Read Text ​

Read text aloud in Prizmo Text Reader.

On-Demand
ts
import { readText } from 'protocol-launcher/prizmo'

const url = readText({
  text: 'Hello World',
  voice: 'Ryan',
})
Read Text in Prizmo
