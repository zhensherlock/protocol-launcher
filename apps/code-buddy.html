CodeBuddy ​

CodeBuddy is a lightweight but powerful source code editor. Protocol Launcher allows you to generate deep links to open and configure resources in CodeBuddy.

Usage ​

There are two ways to use this library:

  • On-Demand import from subpaths enables tree-shaking and keeps bundles small.
  • Full Import from the root package is convenient but includes all app modules.

Pick On-Demand for production builds; Full Import is fine for quick scripts or demos.

Select Installation Method

On-Demand
Recommended. Optimized for production.
Full Import
Convenient. Good for quick scripts.

Open IDE ​

On-Demand
ts
import { open } from 'protocol-launcher/code-buddy'

const url = open()
Open CodeBuddy

Open File ​

On-Demand
ts
import { openFile } from 'protocol-launcher/code-buddy'

const url = openFile({
  path: '/etc/hosts',
  line: 1,
  column: 2,
  openInNewWindow: true,
})
Open in CodeBuddy

Open Folder ​

On-Demand
ts
import { openFolder } from 'protocol-launcher/code-buddy'

const url = openFolder({
  path: '/etc',
  openInNewWindow: true,
})
Open in CodeBuddy

Open Remote ​

On-Demand
ts
import { openRemote } from 'protocol-launcher/code-buddy'

const url = openRemote({
  type: 'ssh-remote',
  host: 'root@172.18.105.209:22',
  path: '/code/my-project',
})
Open in CodeBuddy

Clone Project ​

On-Demand
ts
import { cloneProject } from 'protocol-launcher/code-buddy'

const url = cloneProject({
  repo: 'https://github.com/zhensherlock/protocol-launcher',
})
Open in CodeBuddy

Open Extension ​

On-Demand
ts
import { openExtension } from 'protocol-launcher/code-buddy'

const url = openExtension({
  id: 'esbenp.prettier-vscode',
})
Open in CodeBuddy

Open Settings ​

On-Demand
ts
import { openSettings } from 'protocol-launcher/code-buddy'

const url = openSettings({
  path: 'terminal.integrated.suggest.enabled',
})
Open in CodeBuddy
