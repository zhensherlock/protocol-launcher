RustRover ​

RustRover is an integrated development environment for Rust development. Protocol Launcher allows you to generate deep links to open and configure resources in RustRover.

Usage ​

There are two ways to use this library:

  • On-Demand import from subpaths enables tree-shaking and keeps bundles small.
  • Full Import from the root package is convenient but includes all app modules.

Pick On-Demand for production builds; Full Import is fine for quick scripts or demos.

Select Installation Method

On-Demand
Recommended. Optimized for production.
Full Import
Convenient. Good for quick scripts.

Open File ​

On-Demand
ts
import { openFile } from 'protocol-launcher/rustrover'

const url = openFile({
  path: '/etc/hosts',
  line: 1,
  column: 2,
})
Open in RustRover

Open Folder ​

On-Demand
ts
import { openFolder } from 'protocol-launcher/rustrover'

const url = openFolder({
  path: '/etc',
})
Open in RustRover
