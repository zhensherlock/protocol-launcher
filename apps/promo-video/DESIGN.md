# Protocol Launcher Promo Design

## Style Prompt

A cinematic developer-tool product promo for Protocol Launcher. Dark documentation-inspired canvas, crisp code surfaces, precise motion, and the existing pink-to-cyan lightning identity. The video should feel fast, useful, and trustworthy: a TypeScript object becomes a safe one-click launch URL, then expands into Cursor, Cherry Studio, VS Code, and a broad app ecosystem.

## Colors

- Background: `#121217`
- Surface: `#1B1C24`
- Surface soft: `#242631`
- Foreground: `#F4F1EA`
- Muted text: `#AAA6B3`
- Brand cyan: `#8ACCD5`
- Brand pink: `#FF90BB`
- Brand blue CTA: `#5570F1`
- Code green: `#A6E3A1`
- Warning accent: `#FFD166`

## Typography

- Primary UI and body: `Inter`, `SF Pro Display`, `PingFang SC`, system sans-serif.
- Monospace/code: `JetBrains Mono`, `SFMono-Regular`, `Menlo`, monospace.
- Headlines use heavy weights with generous line height; code stays compact and readable.

## Motion

- Code and URL fragments move with deliberate kinetic precision.
- Scene transitions use fade, scale, and short directional movement, not flashy wipes.
- Logo glow and background protocol lines drift slowly throughout.
- Buttons should feel click-ready: slight scale, glow, and pulse at key moments.

## What NOT to Do

- Do not use generic SaaS landing-page stock imagery.
- Do not make the video only a website scroll recording.
- Do not rely on abstract gradients without product-specific code, URLs, and app actions.
- Do not turn every feature into identical cards; lead with the code-to-link transformation.
- Do not introduce colors outside the palette unless they are syntax-highlight accents.
