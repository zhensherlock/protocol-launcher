Termius ​

Termius 是一款现代化的 SSH 客户端，专为生产力和协作而设计，支持 macOS、Windows、Linux、iOS 和 Android 平台。Protocol Launcher 允许您生成深度链接以打开 Termius 并快速添加新的服务器主机。

使用方式 ​

有两种使用此库的方式：

  • 按需导入（On-Demand）：从子路径导入支持 tree-shaking，保持较小的打包体积。
  • 完整导入（Full Import）：从根包导入更方便，但会包含所有应用模块。

生产构建建议选择按需导入；快速脚本或演示可以使用完整导入。

import { open } from 'protocol-launcher/termius'

On-Demand
ts
import { appHostSharing } from 'protocol-launcher/termius'

const url = appHostSharing({
  label: 'Production Database',
  ip: '192.168.1.100',
  port: 22,
  username: 'admin',
  os: 'linux',
})
