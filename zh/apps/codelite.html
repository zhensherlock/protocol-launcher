CodeLite ​

CodeLite 是一款免费、开源、跨平台的集成开发环境 (IDE)， 专注于 C、C++、Rust、Python、Node.js 和 PHP 开发。Protocol Launcher 允许你生成深度链接，用于在 CodeLite 中打开资源。

使用 ​

提供两种使用方式：

  • 按需加载（通过子路径导入），支持 Tree Shaking，体积更小。
  • 全量导入（从根包导入），使用简单，但会包含所有应用模块。

生产环境建议使用按需加载以减小体积；快速脚本或演示可选择全量导入。

选择安装方式

按需加载
推荐使用。生产环境优化。
全量导入
使用便捷。适合快速脚本。

打开文件 ​

On-Demand
ts
import { openFile } from 'protocol-launcher/codelite'

const url = openFile({
  path: '/etc/hosts',
  line: 1,
  column: 2,
})
在 CodeLite 中打开

On-Demand

import { openFolder } from 'protocol-launcher/codelite'
