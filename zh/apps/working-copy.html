Working Copy ​

Working Copy 是一款功能强大的 iOS Git 客户端，支持克隆、编辑、提交、推送等操作。Protocol Launcher 允许您生成深度链接以在 Working Copy 中执行 Git 操作。

使用方式 ​

有两种使用此库的方式：

  • 按需导入（On-Demand）：从子路径导入支持 tree-shaking，保持较小的打包体积。
  • 完整导入（Full Import）：从根包导入更方便，但会包含所有应用模块。

生产构建建议选择按需导入；快速脚本或演示可以使用完整导入。

选择安装方式

按需加载
推荐使用。生产环境优化。
全量导入
使用便捷。适合快速脚本。

简单命令 ​

打开 ​

打开 Working Copy 应用。

On-Demand
ts
import { open } from 'protocol-launcher/working-copy'

const url = open()
打开 Working Copy

克隆 ​

让 Working Copy 打开克隆对话框并指定 URL。

On-Demand
ts
import { clone } from 'protocol-launcher/working-copy'

const url = clone({
  remote: 'https://github.com/zhensherlock/watermark-js-plus.git',
})
克隆仓库

显示 ​

在 Working Copy 中显示远程仓库，必要时会自动克隆。

On-Demand
ts
import { show } from 'protocol-launcher/working-copy'

const url = show({
  remote: 'https://github.com/zhensherlock/watermark-js-plus.git',
})
显示仓库

打开屏幕 ​

在 Working Copy 中打开特定屏幕。

On-Demand
ts
import { openScreen } from 'protocol-launcher/working-copy'

const url = openScreen({
  repo: 'my project',
  path: 'README.md',
  mode: 'content',
})
打开屏幕

导入日志 ​

导入并显示 Working Copy 中的日志文件。

On-Demand
ts
import { importLog } from 'protocol-launcher/working-copy'

const url = importLog({
  lines: 'first line\nsecond line',
})
导入日志

X-Callback-URL 命令 ​

切换分支 ​

在 Working Copy 中切换分支。

On-Demand
ts
import { checkout } from 'protocol-launcher/working-copy'

const url = checkout({
  key: '123ABC',
  repo: 'my repo',
  branch: 'develop',
})
切换分支

提交 ​

在 Working Copy 中提交更改。

On-Demand
ts
import { commit } from 'protocol-launcher/working-copy'

const url = commit({
  key: '123ABC',
  repo: 'my repo',
  path: '',
  limit: 999,
  message: 'fix',
})
提交更改

移动 ​

在仓库内移动或重命名文件。

On-Demand
ts

const url = move({
  key: '123ABC',
  repo: 'my repo',

读取 ​

从 Working Copy 读取文本文件内容。

On-Demand
ts

const url = read({
  key: '123ABC',
  xSuccess: 'app://x-callback-url/read?text=',
  repo: 'my repo',
  path: 'README.md',
})
读取文件

const url = write({

  repo: 'my repo',
  path: 'README.md',

})
写入文件

压缩 ​

On-Demand
ts

const url = zip({
  key: '123ABC',
  xSuccess: 'my-app://x-callback-url/read?path=/',
  repo: 'my repo',
})
创建 Zip 压缩包

SSH 命令 ​

在远程服务器上运行安全 shell 命令。

On-Demand
ts
import { sshCommand } from 'protocol-launcher/working-copy'

const url = sshCommand({
  key: '123ABC',
  server: 'remote.server.net',
  cmd: 'run tests',
})
运行 SSH 命令

WebDAV ​

启动或停止内部 WebDAV 服务器。

On-Demand
ts
import { webdav } from 'protocol-launcher/working-copy'

const url = webdav({
  key: '123ABC',
  cmd: 'start',
})
切换 WebDAV

链式命令 ​

将多个 x-callback-url 命令链接在一起执行。

On-Demand
ts
import { chain } from 'protocol-launcher/working-copy'

const url = chain({
  key: '123ABC',
  repo: 'my repo',
  commands: [
    { command: 'commit', params: { message: 'fix' } },
    { command: 'push' },
  ],
})
