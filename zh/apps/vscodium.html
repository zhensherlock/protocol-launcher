VSCodium ​

VSCodium 是一个由社区驱动、可自由使用的 Microsoft VS Code 二进制发行版。它基于 MIT 许可构建，默认关闭遥测，并移除了 Microsoft 专有定制。Protocol Launcher 允许你生成深度链接，用于在 VSCodium 中打开并配置资源。

使用 ​

提供两种使用方式：

  • 按需加载（通过子路径导入），支持 Tree Shaking，体积更小。
  • 全量导入（从根包导入），使用简单，但会包含所有应用模块。

生产环境建议使用按需加载以减小体积；快速脚本或演示可选择全量导入。

选择安装方式

按需加载
推荐使用。生产环境优化。
全量导入
使用便捷。适合快速脚本。

import { open } from 'protocol-launcher/vscodium'

打开文件 ​

On-Demand
ts
import { openFile } from 'protocol-launcher/vscodium'

const url = openFile({
  path: '/etc/hosts',
  line: 1,
  column: 2,
  openInNewWindow: true,
})
